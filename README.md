# cookie-cutter

Project templates for [cookiecutter](https://cookiecutter.readthedocs.io).

Install cookiecutter (once):

```sh
pipx install cookiecutter
```

Generate a project from the root of this repository. The new project is
created in the current directory.

## Header-only C++ library

```sh
cookiecutter header-only
```

## Compiled C++ library (static/shared)

```sh
cookiecutter compiled-library
```
